# Alexander Neumorphism Plus

Дополнение к теме Home Assistant **Alexander Neumorphism**. Карточки и саму тему не меняет.

- Значок в кружке плитки чёрный; лунка света разгорается вместе с яркостью — тёплая подсветка и мягкое свечение, вживую во время перетаскивания ползунка
- Лунка иконки вдавленная, тенями самой темы
- Ползунки стеклянные и тоньше: 30 px вместо 42 px, утопленная дорожка, ручка-капсула

Работает только там, где активна тема Alexander Neumorphism (определяется по переменной `--neumorphic-base`), на других темах ничего не делает.

## Установка

HACS → ⋮ → Custom repositories → этот репозиторий, категория **Dashboard** → Download.
Ресурс дашборда добавляется автоматически.
