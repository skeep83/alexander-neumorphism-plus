# Alexander Neumorphism Plus

Дополнение к теме Home Assistant **Alexander Neumorphism**. Карточки и саму тему не меняет.

- Значок в кружке плитки чёрный; лунка света разгорается вместе с яркостью — тёплая подсветка и мягкое свечение, вживую во время перетаскивания ползунка
- Лунка иконки вдавленная, тенями самой темы
- Ползунки стеклянные и тоньше: 30 px вместо 42 px, утопленная дорожка, ручка-капсула

Работает только там, где активна тема Alexander Neumorphism (определяется по переменной `--neumorphic-base`), на других темах ничего не делает.

## Установка

HACS → ⋮ → Custom repositories → этот репозиторий, категория **Dashboard** → Download.
Ресурс дашборда добавляется автоматически.

## Тема Alexander Neumorphism

В папке [`themes/`](themes/) лежит сама тема — `Alexander Neumorphism.yaml` (светлый и тёмный режим).

Стиль «пульт»:

- **Карточки и кнопки** — неоморфные, с двухцветной фаской по краю и мягкими глубокими тенями; вдавленные элементы с «вырезанной» кромкой.
- **Плитки** всегда остаются выпуклыми; состояние показывает светодиод в углу:
  - зелёный — включено;
  - серый — выключено;
  - янтарный, мигает — устройство недоступно;
  - красный — тревога (протечка, дым, газ, неисправность).
- **Иконка плитки и кнопки комнат** работают как клавиши: включено — клавиша вдавлена, выключено — выпуклая.
- **Подсветка клавиш:** клавиша включённой лампы светится её настоящим цветом, сила свечения повторяет яркость и меняется вживую при перетаскивании ползунка (свет и яркость передаёт дополнение из этого репозитория).
- **Фон** — тонкая перфорация, как решётка динамика.
- **Типографика:** моноширинные цифры, повышенный контраст подписей и выключенных иконок (WCAG AA). Переходы — с учётом «Уменьшения движения».

### Установка темы

1. Нужна интеграция [UIX](https://github.com/Lint-Free-Technology/uix): тема стилизует карточки через ключи `uix-*`.
2. Скопируйте `themes/Alexander Neumorphism.yaml` в `/config/themes/`. В `configuration.yaml`:
   ```yaml
   frontend:
     themes: !include_dir_merge_named themes
   ```
3. Выполните действие `frontend.reload_themes` и выберите тему в профиле.
4. Шрифт (необязательно): Nunito Sans в `/config/www/alexander-neumorphism/nunito-sans-variable.ttf`. Без него используется системный.

Дополнение из этого репозитория (`alexander-neumorphism-plus.js`) рекомендуется вместе с темой.
